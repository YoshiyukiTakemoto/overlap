# Overlap Meeting Planner

Free world meeting planner. Compare time zones and find the hour when every city is in working hours. English / 日本語.

- No sign-up, no server, no tracking. Everything runs in the browser.
- Time zone and daylight-saving rules come from the browser's built-in IANA database (`Intl`).

https://yoshiyukitakemoto.github.io/overlap/
